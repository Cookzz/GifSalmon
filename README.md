# GifSalmon

A gif tuning application for Windows only.

I want to emphasize that this branch/build is explicitly experimental only and may not make it to the final build as a viable alternative.

## What has changed

Fully **native WinUI 3** instead of electron

## What has not changed

Maintaining majority UI/UX parity with the electron version

## Why

Doing this to test out if the improvements are worth it to move to native.

Ran some tests but there should be an overall improvement around ~50%.

## Notes

I have done all the testing i could but be aware that bugs may still exist.
